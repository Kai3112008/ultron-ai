ULTRON PWA starter

This is an installable web app (PWA), not a compiled native APK.
To install on Android: host these files on an HTTPS origin, open the site in Chrome, menu > Install app / Add to Home screen.
To enable AI: create a Gemini API key at https://aistudio.google.com/app/apikey and paste it in Settings.
The API key is stored in this browser's localStorage. Do not publish/share this client-side prototype with the key embedded or use it as a public multi-user app. A public release needs a secure backend.
Voice recognition varies by Android browser and installed speech service; typing remains available. Burmese speech support may vary.
Model ID default: gemini-3.8-flash; availability and free quota depend on Google's current account/region policies.
